# Smart Laundry Website

## Project Title
Smart Laundry Service Web Page

## Description
This project is a simple responsive landing page for a Smart Laundry service created using **HTML** and **CSS**. It contains a navigation bar, a hero section, and a call-to-action button. The layout is designed without using Flexbox and uses viewport units (`vh` and `vw`) to fit the screen.

## Features
- Navigation bar with:
  - Logo
  - Home
  - Services
  - About Us
  - Contact Us
  - User Name Box
- Hero section with:
  - Heading
  - Description
  - "Book a Service Today" button
  - Laundry service image
- Responsive layout using viewport units.
- Developed using only HTML and CSS.

## Technologies Used
- HTML5
- CSS3
